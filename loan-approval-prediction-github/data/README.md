# Dataset instructions

The notebook expects `dataset.csv` in the repository root, next to `loan_approval_prediction.ipynb`.

The CSV was not included in the files provided for this revision. Download the permitted educational Loan Prediction dataset from the cited source, verify that it matches the expected columns, and place it in the repository root. The expected original columns include `loan_id`, `gender`, `married`, `dependents`, `education`, `self_employed`, `applicantincome`, `coapplicantincome`, `loanamount`, `loan_amount_term`, `credit_history`, `property_area`, and `loan_status`.

The root `.gitignore` excludes `dataset.csv` by default. Do not upload confidential or personally identifiable data. Verify the dataset's license/terms before redistributing it.
